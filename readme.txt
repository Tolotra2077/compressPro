CompressPro 
bzip2, lzma et 7-zip
benchmark pour évaluer l'efficacité de la compression sur des fichiers (texte, audio, image, vidéo).

Guide d'utilisation

Le script principal s'exécute via le fichier `main.py` en ligne de commande.

python main.py compress-(bz2, lzma ou zip7) mon_fichier
